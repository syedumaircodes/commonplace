## Make the safe path easy

Defaults shape what happens when a caller has not made a choice. A sensible default can prevent an entire class of accidental exposure, while an explicit opt-out keeps exceptional behavior visible in code review.

When choosing a default, document what it protects and how a caller can safely change it.
