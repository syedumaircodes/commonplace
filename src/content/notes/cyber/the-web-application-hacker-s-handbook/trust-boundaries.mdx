## Start with the boundaries

When reviewing an application, trace data from the moment it enters the system to the places where it is interpreted or acted on. Each handoff is a chance for assumptions about **identity, format, or permission** to stop matching reality.

Make a small map of the components and mark the boundaries between them. For each boundary, ask what validates the input, which identity is attached to it, and what the receiving component trusts.
