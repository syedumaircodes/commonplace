Every software stores and manipulates data, most use a relational database and having a well designed and maintained database can make your software better and faster in most aspects.

When handling business expenses and records, a spreadsheet is the go-to solution for storing data and it's quite effective if you store a small amount of data and the data is simple to maintain. If the size of the data increases so will the complexity of maintaining it securely. This is where you use a relational database, they store data in tables that are similar to spreadsheets.

> A table represents an entity and the columns represent it's attributes. A product table inside a database for an e-commerce site can be an entity, as the table will have columns for the product's details.

## Managing relational databases

Relational databases come with their own management systems, software that interacts with the underlying hardware and operating system to physically store and manage relational databases and provides tools to create, modify, and query databases along with other important functions such as security controls.

<Diagram
  label="An RDBMS manages a relational database, which stores data in tables."
  source={`flowchart LR
  RDBMS["RDBMS"] -->|manages| Database[("Relational Database")]
  Database -->|stores| Tables["Tables"]`}
/>

All relational database management systems comes with the structured query language or SQL for working with databases, tables and their data. Vendors have added their own add-ons or syntax changes but SQL is the standard language for interacting with relational databases.
