This phase is a pre-check phase for setting up my system for the course so I don't run into any problems later down the line.

I first completed installing Ubuntu and then setup the required programming languages and their runtimes.

- Python for most tasks including machine learning and model training.
- Node.js and TypeScript for web development, MCPs, and Agents.
- Rust for Inference and performance-heavy workloads.
- Julia for math-heavy workloads.

I skipped installing the GPU drivers as I don't have a dedicated GPU and will use cloud based solutions for it.
